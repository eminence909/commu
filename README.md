# เว็บไซต์พัฒนาชุมชน

เว็บข่าว/กิจกรรม โครงการพัฒนา แจ้งปัญหา + ติดตามสถานะด้วยเลขติดตาม พร้อมระบบแอดมิน
เป็นไฟล์ HTML/CSS/JS ล้วน ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์

## ลองใช้ทันที (โหมดสาธิต)
1. ดับเบิลคลิก `index.html` เพื่อดูหน้าเว็บ
2. เปิด `admin.html` รหัสผ่านโหมดสาธิตคือ `admin1234` (เปลี่ยนได้ใน `js/config.js`)

โหมดสาธิตเก็บข้อมูลในเบราว์เซอร์เครื่องนั้นเท่านั้น (ไม่ข้ามเครื่อง) ใช้สำหรับดูหน้าตาและทดสอบระบบ
พอเชื่อม Google Sheet ตามด้านล่างแล้ว ข้อมูลจะเป็นของจริงที่ทุกคนเห็นตรงกัน

## เชื่อม Google Sheet (ทำครั้งเดียว ประมาณ 10 นาที)
1. สร้าง Google Sheet ใหม่ (ตั้งชื่ออะไรก็ได้)
2. เมนู **ส่วนขยาย > Apps Script** แล้วลบโค้ดเดิม วางโค้ดจาก `apps-script/Code.gs` ทั้งไฟล์
3. แก้บรรทัดบนสุด `ADMIN_PASSWORD` เป็นรหัสผ่านแอดมินของคุณเอง
4. เลือกฟังก์ชัน **setup** แล้วกด **เรียกใช้** กดอนุญาตสิทธิ์ตามที่ขึ้น (ขั้นนี้จะสร้างชีต news, projects, reports, gallery, settings ให้เอง)
5. กด **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > ประเภท: เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
6. คัดลอก URL ที่ลงท้าย `/exec` ไปวางใน `js/config.js` ที่ `API_URL`
7. เปิดเว็บใหม่ ลองแจ้งปัญหา 1 เรื่อง แล้วดูว่าขึ้นในชีต reports และในหน้าแอดมิน

หมายเหตุ: ถ้าแก้ `Code.gs` ภายหลัง ต้องกด **ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่** ถึงจะมีผล

## เอาขึ้นออนไลน์ (ฟรี)
- **Netlify Drop**: ไปที่ app.netlify.com/drop แล้วลากโฟลเดอร์ `community-web` ทั้งโฟลเดอร์ไปวาง ได้ลิงก์ทันที
- หรือ **GitHub Pages**: อัปโหลดไฟล์ขึ้น repository แล้วเปิด Settings > Pages

## ใส่ข้อมูลจริง
ทุกอย่างแก้ผ่านหน้าแอดมิน (`/admin.html`) ได้เลย
- **ตั้งค่าเว็บ**: ชื่อชุมชน ข้อความหน้าแรก ประวัติชุมชน เบอร์ติดต่อ LINE/Facebook แผนที่ รูปพื้นหลัง
- **ข่าวและกิจกรรม / โครงการ**: เพิ่ม แก้ไข ลบ อัปโหลดรูป
- **เรื่องแจ้งปัญหา**: เปลี่ยนสถานะ เขียนข้อความถึงผู้แจ้ง ส่งออก CSV
- **คิวอาร์โค้ดเว็บ**: สร้างคิวอาร์ของลิงก์เว็บ กดบันทึกเป็น PNG/SVG ไปพิมพ์ติดประกาศได้
- **แผนที่**: ดูจุดที่ผู้แจ้งกดปักตำแหน่ง แยกสีตามสถานะ (ต้องมีอินเทอร์เน็ต)

ข้อมูลตัวอย่างในโหมดสาธิตให้ลบหรือแก้ทับก่อนใช้งานจริง

## ความปลอดภัยที่ควรรู้
- ชื่อและเบอร์โทรของผู้แจ้งเห็นได้เฉพาะแอดมิน หน้าติดตามสถานะแสดงแค่ประเภท สถานะ และข้อความจากเจ้าหน้าที่
- อย่าเปิดเผยรหัสผ่านแอดมิน และไม่ควรเก็บข้อมูลอ่อนไหว (เลขบัตรประชาชน ฯลฯ) ในเว็บนี้
- ลิงก์ `admin.html` ไม่ได้ซ่อน แต่ต้องมีรหัสผ่านถึงจะแก้ไขได้

## โครงสร้างไฟล์
```
index.html          หน้าเว็บสาธารณะ
admin.html          ระบบแอดมิน
css/style.css       ดีไซน์และอนิเมชั่นทั้งเว็บ
css/admin.css       ดีไซน์ส่วนแอดมิน
js/config.js        ตั้งค่า API_URL และรหัสโหมดสาธิต
js/data.js          ข้อมูลตัวอย่าง (โหมดสาธิต)
js/api.js           ตัวเชื่อมข้อมูล (สลับโหมดสาธิต/Google Sheet อัตโนมัติ)
js/app.js, admin.js ตรรกะหน้าเว็บและแอดมิน
apps-script/Code.gs โค้ดฝั่ง Google
```
